# Signal Outpost 0.16.18

## Trunked talkgroup filtering

- Add a per-memory allowlist for trunked systems, with searchable imported talkgroups and support for custom decimal talkgroup IDs.
- Enable decoder allow-list mode when a memory has selected talkgroups; encrypted imported talkgroups remain unavailable.
- Include Windows, Linux AppImage / tar.gz, Arch Linux, and macOS packages in this release.
