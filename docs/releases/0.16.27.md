### Added

- WFM broadcast channels can now be scanned by the integrated DSD-neo engine alongside NFM, AM, and digital memories.
- WFM uses a 180 kHz channel filter, 256 kHz RTL capture, 48 kHz mono audio, and 75 μs de-emphasis.
- The app switches between digital voice PCM and analog monitor PCM as the scan advances.

### Notes

- WFM scanning is mono; stereo decoding and RDS are not included in this decoder path.
- The Windows build now calculates the pinned decoder archive checksum using .NET SHA-256, supporting the Windows PowerShell version on the GitHub runner.
