# Signal Outpost 0.16.17

## macOS support

- Add native macOS Intel x64 and Apple silicon arm64 desktop packages.
- Build architecture-matched RTL-SDR, HD Radio, and DSD-neo runtimes from pinned source.
- Bundle Homebrew-linked native dependencies inside the app and verify packaged binary architectures and decoder hashes.
- Publish macOS DMG and ZIP downloads with a separate SHA-256 checksum list.
- Document macOS 13 Ventura minimum, manual updates, Bluetooth permission, and first-launch Gatekeeper approval.

The Mac app is unsigned and not notarized. macOS may require the user to approve opening it under **System Settings → Privacy & Security**.
