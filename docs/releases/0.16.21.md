# Signal Outpost 0.16.21

## Match waterfall tuning to the selected step

- Snap waterfall click targets to the selected tuning step and show that target in the hover tooltip.
- With a 25 kHz step, a click mapping to 102.694252 MHz tunes to 102.700000 MHz.
- Include Windows, Linux AppImage / tar.gz, Arch Linux, and macOS packages in this release.
