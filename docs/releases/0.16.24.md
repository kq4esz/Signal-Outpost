# Signal Outpost 0.16.24

## Faster mixed analog/digital memory scans

- Add mixed-scan dwell choices from 0.5 to 10 seconds per memory.
- Set the default mixed-scan dwell to 1.5 seconds.
- Keep receiver/decoder handoff time separate from the selected dwell; faster dwell may miss brief digital calls.

Windows x64 release of Signal Outpost 0.16.24. Download and run `Signal-Outpost-Setup-0.16.24-x64.exe`. Installed applications receive this version automatically.
