# Signal Outpost 0.16.25

## DSD-neo mixed-mode memory scanning

- Scan conventional NFM, AM, and supported digital memories together in one DSD-neo session.
- DSD-neo changes demodulation and decoder mode from each typed memory row while keeping the RTL-SDR stream open.
- NFM uses noise squelch; AM uses auto squelch. DSD-neo holds on analog carrier and digital calls.
- Choose from no signal hangtime through 10 seconds to control how quickly scanning resumes after activity ends.
- Show the active memory and frequency while scanning. Skip and Stop control the DSD-neo scan.
- Mixed NFM/AM/digital scans require the bundled integrated DSD-neo engine.
