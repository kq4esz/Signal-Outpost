# Signal Outpost 0.11.0

*Tune. Decode. Connect.*

SDR Extreme is now **Signal Outpost**, a radio workspace for amateur radio
operators and scanner enthusiasts.

- Rename the application interface, menus, window titles, About dialog,
  startup updater, and update notices.
- Ship **Signal-Outpost-Setup-0.11.0-x64.exe**, **Signal Outpost.exe**, and
  Signal Outpost desktop and Start menu shortcuts.
- Identify the MeshCore companion client as Signal Outpost and rename exported
  memory files to `signal-outpost-memories.json`.
- Add renamed source launch/setup/stop helpers with compatibility aliases for
  their original names.
- Preserve the existing Windows installation identity and automatic update
  repository, so this release upgrades existing installations.
- Reuse the complete `%APPDATA%\SDR Extreme` profile to preserve saved channels,
  settings, MeshCore history/layouts, and Bluetooth/browser data.

## Upgrade

In SDR Extreme, choose **Help → Check for updates**, wait for the download, then
restart to install. The startup updater introduced in 0.10.2 can also install
this release before opening the receiver. If an older client cannot update,
close it and run the Signal Outpost setup over the existing installation using
the same Windows account and folder. No uninstall or data move is required.

The project and public update releases continue at
https://github.com/kq4esz/Signal-Outpost. Historical release files keep their
original names. The Windows installer remains unsigned.
