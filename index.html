MEMORY LIBRARY

New memory channel

HD Radio program

FM 87.5–108 MHz or AM 0.530–1.710 MHz. The station must transmit this digital program. HD memories are tuned individually.

P25 configuration

Phase 2 voice often uses a Phase 1 control channel. Select the control type used by this site.

Identity fields are optional for trunking. All three are used together as a Phase 2 decoder override when supplied.

NXDN configuration

Choose the system's air interface. NXDN48 and NXDN96 use different decoder settings.

Trunked site

One frequency per line, or LCN, MHz, role. Roles: control, alternate, voice. The control frequency above is included automatically. NXDN sites using a channel map need the correct LCN for each traffic frequency.

When enabled, the decoder follows only the selected talkgroup IDs. Encrypted talkgroups cannot be decoded.

Import a trunked system to browse its talkgroups, or enter IDs below.

With the filter off, all available talkgroups are followed. Add IDs here if they are not in the imported list.

QUICK START

Your receiver, one step at a time.

  1. Allow RTL-SDR USB access.Linux releases include an RTL-SDR driver; configure USB access rules for your user. Windows requires WinUSB for Bulk-In Interface 0. Linux setup is documented in the README.
  2. Connect the dongle.Open Settings, choose your attached USB receiver, then click Start listening.
  3. Pick a signal.Tune by frequency or select a memory. Use AM for airband, NFM for narrowband voice, and USB/LSB/CW for HF.
  4. Decode digital modes.Use the bundled decoder where available, or configure a compatible external decoder. The WSJT-X UDP bridge supports FT8 / FT4 decodes.
